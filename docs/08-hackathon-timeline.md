# 08 – 48h Hackathon Plan

| Time | Focus |
|---|---|
| H0–H3 | Lock idea, persona, MVP scope |
| H3–H12 | Data pipeline + first end-to-end slice |
| H12–H24 | Core features + UI |
| H24–H36 | Polish, validation, edge cases |
| H36–H44 | Pitch deck, demo video, README |
| H44–H48 | Submit early, rehearse, buffer |

## Submission checklist
- [ ] Project title + summary
- [ ] "How we addressed this challenge"
- [ ] "How we used NASA data" (dataset names, versions)
- [ ] Demo link / video
- [ ] GitHub repo (clean README, setup steps)
- [ ] Slides / presentation
- [ ] Team members & credits
- [ ] AI tool usage disclosure (follow Space Apps rules)
